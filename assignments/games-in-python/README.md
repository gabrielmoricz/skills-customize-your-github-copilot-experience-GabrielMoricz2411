
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir o clássico jogo de adivinhar palavras em Python, praticando manipulação de strings, loops, condicionais e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da Forca em que o jogador tenta adivinhar uma palavra oculta, letra por letra, antes de esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas se esgotarem.
- Exibir mensagens de vitória ou derrota.
